# Meeting transcript samples (Microsoft Teams native format)

Sample **Teams meeting transcript** for Doc Knowledge / SharePoint ingest testing.

## Original Teams format (use this file)

Microsoft Teams saves downloadable transcripts as **WebVTT (`.vtt`)** — the same `text/vtt` format returned by [Microsoft Graph callTranscript API](https://learn.microsoft.com/en-us/graph/api/calltranscript-get). Speaker-attributed cues use `<v Speaker Name>` voice tags.

| File | Description |
|------|-------------|
| **`Travel Planner AI Agent-20250822_100000-Meeting Transcript.vtt`** | **Native Teams transcript** (~30 min, 113 cues) |
| `Travel-Planner-Agent-Discovery-2026-08-22.meta.json` | Sidecar metadata only (not produced by Teams) |

> **Note:** Teams **DOCX** transcript export was **deprecated 31 May 2023**. Do not use custom Markdown or Word for pipeline input if you want to match what Teams/Graph provides. Convert to text later in your own processing if needed.

## Where Teams saves transcripts (SharePoint Enterprise)

When transcription is enabled and the meeting ends, artifacts are stored under the **organizer’s OneDrive** or the **team SharePoint site**:

```text
{Enterprise Site}/Shared Documents/Recordings/
  Travel Planner AI Agent-20250822_100000-Meeting Transcript.vtt
  Travel Planner AI Agent-20250822_100000.mp4          (recording or transcript-only container)
```

For **channel meetings**, the path is the team’s SharePoint **Documents → Recordings** library (same pattern).

For **Doc Knowledge testing**, you may copy the `.vtt` into a folder such as:

```text
Shared Documents/meeting transcript/
```

Teams does not create a `meeting transcript` folder by default — that is optional for your ingest layout.

## Upload steps

1. Open your Enterprise SharePoint site → **Documents** (or **Shared Documents**).
2. Create **`Recordings`** (Teams default) or **`meeting transcript`** (your test folder).
3. Upload **`Travel Planner AI Agent-20250822_100000-Meeting Transcript.vtt`** unchanged — do not rename the extension.
4. Enable Doc Knowledge + Graph list permissions (see `docs/DOCUMENT_KNOWLEDGE_FABRIC.md`).

## Processing later

Your ingest pipeline can parse `.vtt` directly (WebVTT + `<v Name>` tags). Convert to plain text, Markdown, or DOCX **after** download — not before upload to SharePoint.
