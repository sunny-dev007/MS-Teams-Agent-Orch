Agent Overview

Welcome to the WhatsApp AI Agent Portal. This platform allows you to manage your engineering tasks through WhatsApp messages.

Capabilities

Email Management

Read and classify emails, send new emails, and manage your inbox efficiently.

Calendar Scheduling

Schedule meetings, create events, and integrate with Google Calendar.

Repository Browsing

Browse and manage your repositories on GitHub and Azure DevOps.

Code Development

Develop code, review changes, and deploy to production with human approval.
