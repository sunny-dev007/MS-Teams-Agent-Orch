Sunny's Personal AI Agent Portal

Your intelligent assistant for managing emails, meetings, code repositories, and more.

Overview

This AI agent helps you streamline your daily tasks by integrating with your Gmail, Calendar, GitHub, and Azure DevOps accounts. It can read and summarize your emails, schedule meetings, manage your code repositories, and assist with code reviews and deployments.

Features

  • Email Management: Check your emails, get summaries, and suggested actions.
  • Meeting Scheduling: Schedule meetings with natural language commands and calendar integration.
  • Repository Wizard: Browse and manage your GitHub and Azure DevOps repositories.
  • Code Assistance: Request code changes, reviews, and deployments through conversational commands.
  • Status Tracking: Monitor task statuses and get updates on your ongoing requests.

Getting Started

Interact with the agent via WhatsApp by sending commands such as:

  • hello - Greet the agent
  • help - Get a list of available commands
  • check my emails - Receive a digest of your recent emails
  • schedule a meeting tomorrow 4pm with john@example.com titled Sync - Schedule a meeting
  • check my repos - Browse your code repositories
  • task status - Check the status of your tasks

For detailed instructions and examples, please refer to the WhatsApp E2E Test Guide.
